# Editorial cover pilots

Five illustrations generated for QuizzUp on 2026-10-19: Blue Lock, JoJo's
Bizarre Adventure, Saint Seiya, Fairy Tail and Haikyū!!.

These are generated fan illustrations, not official screenshots. The shared
composition reserves the bottom quarter for an accessible HTML caption.
Titles are never baked into the image. Assets are served locally as 768px
square WebP files; source PNGs are retained in the creator's generated-images
folder. Existing explicit category covers keep priority.

Keep this as a five-topic pilot until the art direction is reviewed in the
mobile grid. Do not expand automatically to unrelated topics.
